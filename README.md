# MediCare Hub

MediCare Hub is a Hospital Management System developed using Django and Python.  
This project helps manage hospital operations such as patient records, doctor management, appointments, and admin functionalities through a simple web interface.

## Features

- Admin Dashboard
- Doctor Management
- Patient Management
- Appointment Booking
- User Authentication
- Responsive User Interface
- Secure Login & Logout System

## Technologies Used

- Python
- Django
- HTML
- CSS
- Bootstrap
- SQLite
